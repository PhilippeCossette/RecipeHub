## 📖 About

RecipeHub is a modern full-stack recipe platform where users can discover and save recipes.

The project focuses on building a scalable application using the modern React ecosystem, emphasizing reusable components, server-side data fetching, authentication, and a clean developer experience.

> **Note**
>
> The current version prioritizes functionality and architecture. A complete UI redesign with custom components and branding is planned for a future release.

## ⚙️ Getting Started

Clone the repository

```bash
git clone https://github.com/PhilippeCossette/recipehub.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Create your environment variables

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

Build for production

```bash
npm run build
```
